# VK Beauty Assistant Bot

Ежедневный (около 8:00 по Москве) дайджест в Telegram:
- 🔎 топ-посты твоих конкурентов за сутки
- 🔥 горячие темы/инфоповоды в бьюти-нише с готовым углом подачи

Ничего не лайкает и не постит автоматически — только присылает подборку тебе в чат.

## Файлы

- `bot.py` — весь код бота
- `requirements.txt` — зависимости
- `Procfile` — команда запуска для хостинга (Railway)

## Настройка перед запуском

Открой `bot.py`, в самом верху (раздел "НАСТРОЙКИ") впиши свои значения — либо прямо в код,
либо (безопаснее) через переменные окружения на хостинге:

| Переменная            | Где взять |
|------------------------|-----------|
| `VK_SERVICE_TOKEN`     | Настройки твоего VK-приложения → Ключи доступа → Сервисный ключ |
| `TELEGRAM_BOT_TOKEN`   | @BotFather → /newbot (или /mybots → API Token) |
| `TELEGRAM_CHAT_ID`     | Можно оставить пустым при первом запуске — бот сам покажет его в логах после того, как ты напишешь ему /start |

Список конкурентов — в списке `COMPETITORS` (короткие имена из ссылок vk.ru/ИМЯ).
Ключевые слова ниши — в списке `NICHE_KEYWORDS`, можно дополнять своими.

## Деплой на Railway (бесплатно, ~15 минут)

1. Зайди на https://railway.app, зарегистрируйся (можно через GitHub)
2. Нажми **New Project → Deploy from GitHub repo** — если репозитория нет,
   можно также выбрать **Empty Project**, а потом залить файлы через встроенный редактор
   (или через Railway CLI, если удобнее)
3. В настройках проекта (**Variables**) добавь переменные окружения:
   - `VK_SERVICE_TOKEN`
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID` (можно оставить пустой на старте)
4. Убедись, что команда запуска — `python bot.py` (это уже прописано в Procfile)
5. Нажми **Deploy**

## Первый запуск — получаем chat_id

1. После деплоя открой **Logs** в Railway — там будет сообщение
   "жду, пока ты напишешь /start боту в Telegram..."
2. Открой своего бота в Telegram, нажми **Start** (или напиши `/start`)
3. В логах Railway появится строка вида:
   `>>> Твой TELEGRAM_CHAT_ID: 123456789 <<<`
4. Скопируй это число, вставь в переменную `TELEGRAM_CHAT_ID` в Railway → Variables
5. Перезапусти сервис (Redeploy)

После этого бот сам, каждое утро, без твоего участия, будет присылать дайджест.

## Безопасность

После того как всё заработало — рекомендуется перевыпустить оба ключа
(VK сервисный ключ можно обновить в тех же настройках приложения,
Telegram-токен — командой `/revoke` у @BotFather), чтобы старые значения,
которые попадали в переписку, перестали действовать.
